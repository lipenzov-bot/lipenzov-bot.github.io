Политика конфиденциальности NewMove CRM

Действует с 26 сентября 2026 года

NewMove CRM — внутренняя программа учёта закупок и договоров. Это не общедоступный сервис: подключить к ней можно только рабочие почтовые ящики, и только с согласия владельца каждого ящика.

Какие данные программа получает

Письма рабочего ящика Gmail, к которому владелец дал доступ на странице Google: отправитель, получатели, тема, дата, текст и вложения.

Что программа с ними делает

  • Только читает. Доступ — «просмотр писем» (gmail.readonly). Программа не отправляет, не удаляет и не изменяет письма.
  • Разбирает письма площадок, заказчиков и контрагентов: заявки, протоколы, договоры, гарантийные обращения, документы. Результат попадает во внутреннюю CRM.

Где хранятся данные

  • На компьютерах владельца программы. Ключ доступа к ящику хранится в зашифрованном виде средствами Windows.
  • Письма не публикуются и не выкладываются в открытые места.

Кому данные передаются

  • Не продаются, не передаются третьим лицам для их целей и не используются для рекламы.
  • По поручению владельца письма может разбирать ИИ-помощник — только чтобы выполнить это поручение. Программа не использует письма для обучения моделей ИИ.
  • Использование и передача сведений, полученных через API Google, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ и удалить данные

  • Отозвать доступ владелец ящика может в любой момент на странице myaccount.google.com/permissions. После этого программа больше не читает ящик.
  • По просьбе владельца ящика сохранённые копии его писем удаляются. Связь — по адресу поддержки, указанному на экране согласия Google.

Privacy policy (summary in English)

NewMove CRM is an internal procurement-tracking tool. It is not offered to the public. It connects only to business Gmail mailboxes, with each mailbox owner's consent.

It requests read-only access (gmail.readonly) and never sends, deletes or modifies mail. Messages are processed to track tenders, contracts, warranty requests and documents in the internal CRM, stored on the owner's computers, with the access token encrypted by Windows. Data is not sold, not shared with third parties for their purposes, not used for advertising, and not used to train AI models. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions; stored copies are deleted on request via the support address shown on the Google consent screen.
